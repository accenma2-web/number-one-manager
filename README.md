# NUMBER ONE – النجمي

تطبيق إدارة محل بلايستيشن: ثلاثة أجهزة، جلسات بمدة محددة، تنبيه قبل الانتهاء بخمس دقائق وعند الانتهاء، مبيعات المنتجات، المصروفات، والتقارير.

## النشر
فعّل GitHub Pages من Settings → Pages → Deploy from a branch، ثم اختر `main` والمجلد `/(root)`.

## التثبيت على الهاتف
افتح رابط GitHub Pages من Chrome على Android، ثم قائمة المتصفح واختر **Install app** أو **Add to Home screen**.

## ملاحظات
- البيانات محفوظة محليًا في المتصفح على نفس الجهاز.
- لا يوجد اتصال أو تحكم مباشر بأجهزة PlayStation.
- الإشعارات تعتمد على سماح المتصفح؛ لا يمكن ضمان تنبيه دقيق إذا أُغلق المتصفح أو أوقف النظام عمله بالخلفية.
